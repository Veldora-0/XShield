PHASE 6 HEURISTIC TELEMETRY

Behavioral Intelligence & Context

Quantifies attack velocity, targeting repetition, and indicator diversity across recent application events to derive explainable operational threat context.

Four Core Behavioral Heuristic Signals

Application Context Evaluation
SIGNAL 1 {{ "DETECTED" if behavior.repeated_activity else "CLEAR" }}

Repeated Suspicious Activity

Triggers when multiple flagged or blocked events originate within the active evaluation window for the current application.

Threshold: ≥ 2 suspicious events in recent history
SIGNAL 2 {{ "DETECTED" if behavior.endpoint_repetition else "CLEAR" }}

Normalized Endpoint Targeting

Triggers when an attacker repeatedly targets the same application route (e.g. /search or /login) with varying payloads.

Threshold: ≥ 3 events targeting the identical endpoint
SIGNAL 3 {{ "DETECTED" if behavior.burst_activity else "CLEAR" }}

Short-Window Event Burst

Flags automated or tool-assisted probing where request velocity exceeds ordinary human interaction speeds.

Threshold: ≥ 4 events within a 60-second burst window
SIGNAL 4 {{ "DETECTED" if behavior.pattern_diversity else "CLEAR" }}

Detection Pattern Diversity

Identifies multi-vector attacks where an adversary rotates between script tags, event handlers, and encoded URL schemes.

Threshold: ≥ 2 distinct rule categories matched in history
