CORE ARCHITECTURE

Multi-Stage Explainable Defense

XShield unites deterministic indicator rules with sequence learning and temporal incident correlation.

1. Heuristic Rule Detector

Six explainable indicator categories analyze bounded, case-folded input using single-layer decoding to identify markup, script execution functions, and event handlers without execution.

  • R001–R006 Active Rules
  • Single-layer entity decoding
  • Zero payload execution

2. Character-Level ML Model

Sub-token character n-grams (3 to 5 characters) capture recurring syntax fragments, delimiters, and obfuscated sequences paired with a balanced linear classifier.

  • 54,919 character n-gram features
  • Calibrated XSS probability
  • 99.90% held-out test accuracy

3. Behavioral & Incidents

Phase 6 behavioral intelligence tracks burst velocity and repeated endpoint probes, while Phase 7 correlation clusters related multi-event incidents dynamically.

  • Deterministic incident IDs
  • Burst & pattern diversity heuristics
  • Application-isolated event history
