Evaluation Methodology & Scientific Limitations

Held-Out Test Set Isolation

The held-out test split of 3,967 samples was never used to fit the TF-IDF vectorizer or Logistic Regression classifier. It was strictly isolated until offline model evaluation.

Class Imbalance Context

The test set contains 3,861 benign parameter strings and 106 XSS attacks. Because of this natural imbalance, F1-score and Recall are the primary indicators of defensive efficacy rather than raw accuracy alone.

Important Research Disclaimer

These benchmark results apply specifically to the selected HttpParamsDataset held-out test split. They are not real-world guarantees of detecting 100% of all future, fragmented, or polymorphic XSS attacks. XShield is a defensive risk-assessment prototype and must be paired with trusted output encoding and web application firewalls in production.
