Hybrid Detector Fusion Analysis

The hybrid pipeline combines the heuristic score (50%) and the final ML probability (50%). On three payloads where the rule score was low (scores 20–40) despite triggering an alert, the combined linear signal fell just below the 0.50 decision threshold, resulting in 11 false negatives on this offline test set. This demonstrates the empirical trade-off of strict equal-weighted fusion without heuristic override logic.

Evaluation Methodology & Scientific Limitations

Held-Out Test Set Isolation

The held-out test split of 3,967 samples was strictly isolated from training. Neither the TF-IDF vectorizer nor the Logistic Regression classifier was fitted on any sample from this evaluation benchmark.

Class Imbalance Context

The test set contains 3,861 benign parameter strings and 106 XSS attacks. Because of this natural imbalance, F1-score and Recall are the primary indicators of defensive efficacy rather than raw accuracy alone.

Important Research Disclaimer

These are offline held-out benchmark results and are not production guarantees. Benchmark performance does not equal real-world attack detection coverage against novel, fragmented, or polymorphic evasion techniques. XShield is designed as a defense-in-depth risk-assessment layer and must be paired with contextual output encoding, strict CSP headers, and web application firewalls in production.
